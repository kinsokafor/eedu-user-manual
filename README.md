# eedu.ng User Manual

The source of the eedu.ng user manual, published with GitBook.

- `gitbook-docs.yaml` — the GitBook site structure (one section, **User Manual**).
- `documentation/` — the manual's pages. `SUMMARY.md` there is the table of contents; `README.md` is the welcome page.

Edit pages in GitBook or here; GitBook Git Sync keeps both in step. Keep links between pages relative (for example `dean.md#publishing-results`).
