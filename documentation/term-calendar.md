# Term Calendar: What to Do and When

A checklist of the recurring tasks in an eedu.ng school year, with who does each one. Links go to the detailed steps.

**Roles:**
- **PM:** Portal Manager
- **SA:** School Admin
- **DN:** Dean (or HOD in tertiary institutions)
- **BR:** Bursar
- **FT:** Form Teacher
- **T:** Teacher

---

## Before the term opens

| Task | Who | Steps |
|---|---|---|
| Set the **Active Session** to the new term | PM | [Changing term](portal-manager.md#moving-to-the-next-term) |
| Check the **class list**: new admissions, leavers archived, class changes | SA, DN | [Manage Class List](school-admin.md#manage-class-list) |
| Admit new students, singly or by **import** | SA, DN | [Students](school-admin.md#students) |
| Add new staff, and assign each teacher's **subjects** | SA, PM | [Staff](school-admin.md#staff) |
| Update **form teachers** if they've changed | PM | [School Settings](portal-manager.md#form-teachers) |
| Set the **term's opening and closing dates** and **holidays** | SA, BR | [Attendance](school-admin.md#attendance) |
| Create the **term's fees** | BR | [Fees](bursar.md#creating-a-fee) |
| Publish **class book lists** and **book packs** | BR | [Bookstore](bursar.md#class-book-lists) |
| **Copy last term's timetable**, then review and publish each class | DN | [Timetables](dean.md#timetables) |
| Create the term's **exams** (CA tests, mid-term, examination) | DN | [Creating the exam](dean.md#1-creating-the-terms-exam) |
| Print **ID cards** for new students and staff | PM | [ID cards](portal-manager.md#id-cards-software-engineer) |

## During the term

| Task | Who | How often |
|---|---|---|
| Clock students and staff in and out at the gate | Security | Daily |
| Record wallet top-ups and fee payments at the bursary | BR | As they come |
| Send **debtor reminders** by SMS | BR | Every few weeks |
| Post expenses and other **journal entries** | BR | Weekly |
| Enter **CA scores** as each test is marked (or send CBT scores to the gradebook) | T | After each test |
| Publish **lessons** and **assignments**; mark and return work | T | Weekly |
| Record **behaviour**; follow up concerns | T, FT | As it happens |
| Review **Pastoral Overview**: follow-ups, repeat concerns, safeguarding flags | SA, DN | Weekly |
| Check **Track latest updates** for score-entry progress | DN | Weekly in the second half of term |

## End of term: results season

1. **Teachers** finish entering all scores (**Update Result**). *Deadline set by the Dean.*
2. **The Dean** checks progress (the Update Result side panel, Track latest updates, and the HOD's department progress) and follows up.
3. **Form teachers** check their class **broadsheet** for missing scores.
4. **The Dean or form teachers publish** each class from the broadsheet. See [Publishing results](dean.md#publishing-results).
5. **Form teachers** adjust any **report card comments** on Print Result, *after* the final publish.
6. **Print report cards** (Print Result), or let parents view them online. If results need scratch cards, sell the cards: parents unlock results from the home page.
7. **The bursar** prints clearance bills for debtors and sends a final reminder.
8. **The Portal Manager** moves the school to the next term (Active Session).

## End of session: promotion

1. After the third term's results are published, **the Dean** opens the **Annual Broadsheet** for each class and checks the *Promoted / Not promoted* comments. If one looks wrong, check the scores and the **Promotion Control** rules. See [Annual results](dean.md#8-annual-results-and-promotion).
2. **Publish** annual results (Dean, HOD, School Admin or Portal Manager), then print annual report cards.
3. **The Portal Manager** sets the **Active Session** to the new session and First Term. Promoted students move up a class automatically, and final-year students become Alumni. See [New session](portal-manager.md#moving-to-a-new-session-promotion).
4. **School Admin or Dean** reviews the new class lists and corrects individual students.
5. Continue with **Before the term opens** above.

## Troubleshooting

| Problem | Likely cause | Fix |
|---|---|---|
| A teacher sees "You are yet to select a subject" or no subjects | No subjects assigned on their staff profile | SA or PM: staff profile → **Subjects** |
| A student isn't on a teacher's score list | Not in that class and stream for the active term | SA: **Manage Class List** |
| A result isn't showing for a student | Not published, or waiting for a scratch card PIN | Publish from the broadsheet; or the student uses **Check Results** with a PIN |
| A published result doesn't show a corrected score | Changes after publishing need republishing | Publish the class again from the broadsheet |
| "Exam … already exists for this study cycle" | An exam with that name exists this term | Use a different name, or edit the existing exam |
| A new fee wasn't created for a class | That class and stream already has a fee this term | Edit the existing fee's amount |
| Canteen or bookstore refuses sales | The accounts aren't set | BR: Canteen Settings and Bookstore Settings |
| A student can't buy in the canteen | Wallet balance too low or daily limit reached | Top up at the bursary |
| Parents' SMS isn't sending | Bulk SMS not enabled, no SMS units, or no phone number on record | Ask support to enable it; recharge units; update the student's phone number |
| Timetable, CBT, Lessons, Bookstore or Pastoral missing from menus and dashboard | Feature switched off for the school | Ask eedu.ng support to switch it on |
| "User already checked in for the current date" at the gate | The person is already clocked in | Clock them out first |
| A lecturer signs in and sees a missing page | The Lecturer portal isn't built yet | See the note in the [Teacher manual](teacher.md#lecturers) |
